# กติกาโหมดทำงานข้ามคืน (Guardrails)

เพราะไม่มีมนุษย์คอยดู กติกาเหล่านี้เข้มกว่าปกติ และ **ห้ามฝ่าฝืนไม่ว่าเหตุผลใด**

## ห้ามเด็ดขาด
- ติดตั้ง dependency ใหม่โดยไม่บันทึกเหตุผลใน PROGRESS (ถ้าจำเป็นให้ใช้น้อยที่สุด)
- สแครปเว็บร้านค้าเกินกติกา Polite Scraping ใน `CLAUDE.md` (ใช้ข้อมูลตัวอย่าง/แคชที่มีอยู่ในการทดสอบ)

## ขอบเขตงาน
- แกนวิชาการของ ML (`CLAUDE.md` หัวข้อ 2) เปลี่ยนไม่ได้ เว้นแต่มีงานใน Ready ระบุไว้ตรงๆ
- ทุกงานด้าน UI ต้องตรง `.claude/skills/design.md` ถ้าเห็นว่าสัญญาการออกแบบมีปัญหา ให้เขียนข้อเสนอลง `## Ideas` ห้ามแก้ `.claude/skills/design.md` เอง
- งานหนึ่งชิ้นควรเปลี่ยนไม่เกิน ~300 บรรทัด ถ้าใหญ่กว่านั้นให้แตกเป็นงานย่อย
- ห้ามเริ่มงานที่ไม่อยู่ใน Ready (ไอเดียใหม่ต้องผ่านการเขียนเป็นงานพร้อมเกณฑ์ผ่านก่อน)

## ประตูคุณภาพก่อนนับว่างานเสร็จ
1. `reviewer` ตัดสิน `VERDICT: PASS`
2. `user-tester` ตัดสิน `VERDICT: ACCEPT`
3. เทสต์ที่มีอยู่ผ่านทั้งหมด (ถ้าเทสต์ก่อนหน้าเคยผ่านแล้วตอนนี้ล้ม ถือว่างานนี้ทำให้ถอยหลัง ต้องแก้หรือย้อนกลับ)

## ป้องกันการวนเปล่า
- ไอเดียต้องตอบได้ว่า "ผู้ใช้ตัดสินใจซื้อได้เร็วขึ้น/มั่นใจขึ้น/ใช้ง่ายขึ้นอย่างไร" ถ้าตอบไม่ได้ไม่ต้องทำ
- ห้ามแก้งานที่ผ่านแล้วซ้ำไปมาเพียงเพราะรสนิยม ต้องมีหลักฐานจาก user-tester หรือ reviewer
- ถ้ามีงานเดียวกันถูกย้ายไป Blocked 2 ครั้ง ห้ามหยิบกลับมาทำอีก
